# صفحات رشفة

هذا المجلد يحتوي صفحات جاهزة للنشر (كل صفحة ملف HTML واحد مستقل، بدون أي اعتمادات خارجية غير خطوط جوجل).

## الملفات
- `index.html` — يحوّل تلقائياً إلى المينيو (يمكنك حذفه أو تعديله إذا تبين صفحة رئيسية مختلفة)
- `menu.html` — صفحة المينيو
- `order.html` — صفحة "طريقة الطلب"

## طريقة النشر (أي من هذه الخيارات)
- **Netlify / Vercel**: اسحبي هذا المجلد كامل إلى صفحة الرفع (drag & drop) في Netlify Drop أو مشروع جديد في Vercel
- **GitHub Pages**: ارفعي الملفات لمستودع GitHub، فعّلي Pages من إعدادات المستودع
- **أي استضافة عادية (cPanel/FTP)**: ارفعي محتويات المجلد مباشرة داخل `public_html` أو المجلد الجذر للموقع

## ملاحظات
- الصور مضمّنة داخل ملفات HTML نفسها (base64)، فلا حاجة لرفع صور إضافية
- الروابط (انستقرام وواتساب) شغّالة فعلياً وتفتح في تبويب جديد
